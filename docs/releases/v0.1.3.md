# public-wt v0.1.3

**Released:** 2026-11-02 · **Commit:** `ef2ed9d` · **Previous:** [v0.1.2](v0.1.2.md)

## What it does

Cycle-level stall profile of any gfx1100 kernel (hipcc, Mojo, hand asm) from a real SQTT thread trace
on the 7900 XTX, through tinygrad's KFD runtime. Shows, per instruction, how many cycles each wave
waited before it issued.

```
                    run_hsaco.py                       wavewait (Mojo)
k.hsaco ──► tinygrad custom kernel ──► sqtt-capture ──► profile.pkl ──► per-pc table
           (ELF swapped in, hidden     (SQTT,                       (llvm-objdump pc map,
            kernargs filled)            WGP 3 pinned)                  waves walked by packet)
```

## Highlights

- Profile PyTorch ROCm jobs with no change to the job: see `docs/pytorch.md`.
- `wavewait rank` ranks a whole process's kernels from its kernel trace.
- `tools/comfy-trace.sh` traces one ComfyUI run with stages, CPU and Python stacks.

## Changes

### Added
- `wavewait rank`, with true GPU busy and per-node rows through `--stages`.
- `tools/att-capture.sh`, with `ATT_EXTRA` and `ATT_SLIM`, and `tools/torch-e2e.sh`.
- ComfyUI tracing: `tools/comfy-trace.sh` and its helpers.
### Fixed
- The walk follows code objects with many kernels and MIOpen's Sp3 kernels.
- `ATT_*` overrides now cross `gpu-wait`.

## Known limits

- 9 of 44 torch dispatches differ from AMD on `s_waitcnt` rows after `ds_store_b128`: 2.4 cycles per hit on the matmul; issues and hits are exact.
- SQTT cold runs mislead: trace a warm dispatch.
- One GPU reset came during a ComfyUI server preflight, cause not proven.
