## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Cycle-level stall profile of any gfx1100 kernel (hipcc, Mojo, hand asm) from a real SQTT thread trace
on the 7900 XTX, through tinygrad's KFD runtime. Shows, per instruction, how many cycles each wave
waited before it issued.

```
                    run_hsaco.py                       wavewait (Mojo)
k.hsaco ──► tinygrad custom kernel ──► sqtt-capture ──► profile.pkl ──► per-pc table
           (ELF swapped in, hidden     (SQTT,                       (llvm-objdump pc map,
            kernargs filled)            WGP 3 pinned)                  waves walked by packet)
```

## Highlights

- Pick one dispatch or kernel out of an app trace: `app --dispatch N`, `app --kernel NAME`.
- `--loops` folds loop iterations and keeps the cycle totals.

## Changes

### Added
- `app --dispatch/--kernel` and `--loops`.
- A trace cut before every wave ends warns about open waves.
### Fixed
- A wave whose packet lands past `s_endpgm` is dropped instead of aborting the walk.
- INST ops 0x2f to 0x36 (buffer) are classed as memory.
- `build/wavewait` carries an rpath to the Mojo runtime libraries.
